## 증거의 출처부터 기록하기

증거가 어디서, 언제, 누구에 의해, 어떤 도구와 설정으로 수집됐는지 기록합니다. 원본을 보존하고 분석은 사본에서 수행합니다. 파일의 SHA-256 해시는 이후 같은 바이트인지 확인하는 데 쓰이며, 내용이 사실이거나 수집이 완전하다는 것까지 보장하지는 않습니다.

| 기록 항목 | 예시 형식 |
| --- | --- |
| 사건·증거 식별자 | CASE-001 / EVID-001 |
| 출처 | 장비 식별자, 로그 채널, 원래 경로 |
| 수집 시간 | 시간대가 포함된 날짜와 시각 |
| 방법 | 도구·버전·매개변수·권한 |
| 무결성 | 해시 알고리즘과 해시값 |
| 인계·보관 | 담당자, 저장 위치와 접근 기록 |

## 시간의 의미 구분하기

**발생 시간**, **기록 시간**, **수집 시간**, **SIEM 수집 시간**을 구분합니다. UTC로 비교하더라도 원래 시간대와 변환 방법을 남깁니다. 장비 시계의 오차, 로그 전달 지연과 DST도 확인합니다.

파일 생성·수정 시간은 사건의 모든 행동을 직접 증명하지 않습니다. 복사, 압축 해제, 정상 프로그램과 시간 변경의 영향이 있을 수 있어 프로세스·로그·통신을 함께 봅니다.

## 타임라인의 최소 열

| 시각 및 시간대 | 출처 | 장비·계정 | 관찰된 행동 | 해석·신뢰도 |
| --- | --- | --- | --- | --- |
| 2026-10-07T00:00:00Z | 로그 식별자 | LAB-HOST / lab-user | 인증 성공 | 접근 의도는 후속 기록 필요 |

위 행은 형식 설명을 위한 가상 예시입니다. 확인되지 않은 가설을 관찰된 행동 열에 넣지 않습니다. 서로 다른 센서의 식별자가 같은 사건을 가리키는지 확인한 뒤 연결합니다.

## 무결성 확인 예시

이미 수집한 **사본 파일**에 실행하는 읽기 전용 예시입니다.

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Security.evtx
```

```bash
sha256sum Security.evtx
```
