## 이 가이드의 목표와 준비물

DFIR은 디지털 흔적으로 사건을 설명하고 피해를 줄이는 활동입니다. 이 글의 목표는 **경보 한 개를 근거가 있는 조사 기록으로 바꾸는 것**입니다. 첫 실습에는 실제 침해 장비가 필요하지 않습니다. [첫 조사 실습](first-investigation.html)의 가상 로그와 메모장을 준비합니다.

디지털 포렌식은 수집·검사·분석을 통해 무엇이 일어났는지 설명하고, 침해사고 대응은 확산 억제·원인 제거·복구를 실행합니다. NIST SP 800-86과 SP 800-61 Rev. 3은 각각 포렌식 기법과 위험 관리에 연결된 대응을 이해하는 출발점입니다. 아래 단계는 학습용 조사 절차이며 모든 사고에 고정된 순서는 아닙니다.

## 1단계 — 한 문장으로 조사 목표 정하기

처음부터 ‘공격자를 찾아낸다’고 시작하면 범위가 너무 넓습니다. “파일 서버에서 만들어진 예약 작업을 누가 요청했고 실제로 무엇이 실행됐는지 확인한다”처럼 대상과 행동을 정합니다.

1. 경보 원문 또는 의심 기록을 그대로 보존합니다.
2. 장비·계정·시각·출처를 적습니다. 빈 항목은 추측해서 채우지 않습니다.
3. 이미 확인된 행동과 앞으로 확인할 행동을 분리합니다.

**남길 결과:** 사건 번호, 시작 근거, 조사 대상, 최초 시간 범위를 포함한 짧은 조사 메모입니다.

## 2단계 — 자료가 있는 곳을 먼저 확인하기

| 알고 싶은 내용 | 먼저 볼 자료 | 자료가 없을 때 |
| --- | --- | --- |
| 누가 접속했는가 | 대상의 인증 로그 | 감사·보존·전달 상태 확인 |
| 무엇이 실행됐는가 | 프로세스 생성 기록 | EDR·실행 아티팩트 등 다른 출처 검토 |
| 어디와 통신했는가 | 연결 로그·PCAP | 센서 위치·패킷 보존 범위 확인 |
| 무엇이 바뀌었는가 | 작업·서비스·파일 변경 자료 | 이전 상태와 현재 상태 비교 가능 여부 확인 |

네트워크 자료가 계속 쌓여도 호스트 자료가 자동으로 쌓인다고 가정하지 않습니다. 필요할 때만 수집하는 운영에서는 사건 시점에 남아 있는 로그를 별도로 가져와야 합니다.

**확인할 결과:** 각 자료의 소유 시스템, 대상 기간, 수집 방법, 접근 권한이 정리돼 있어야 합니다. 비어 있는 데이터 영역도 결과입니다.

## 3단계 — 원본과 분석 사본 만들기

증거 식별자를 부여하고 수집한 파일, 수집 기록, 해시를 보관합니다. 분석은 별도 사본에서 시작합니다. 살아 있는 장비를 조회하면 새로운 프로세스와 로그가 발생할 수 있으므로 실행 명령과 시각도 기록합니다.

세부 절차는 [증거 보존과 타임라인](evidence-timeline.html)을 따릅니다. 해시는 파일의 바이트가 바뀌었는지 확인하는 도구이며 기록 내용의 진실성이나 수집의 완전성까지 증명하지 않습니다.

## 4단계 — 시간순으로 행동을 연결하기

‘인증 → 설정 변경 → 실행 → 통신’이 관찰됐는지 출처별로 확인합니다. 한 로그에서 모든 과정을 찾으려고 하지 않습니다. 시간만 비슷한 두 이벤트는 후보 연결이며 같은 세션·계정·장비 등 추가 연결점이 필요합니다.

| 구분 | 작성 예시 |
| --- | --- |
| 사실 | 파일 서버의 Security 로그에 작업 생성 이벤트가 있다 |
| 해석 | 해당 계정의 관리 작업일 가능성이 있다 |
| 대안 | 계정이 악용됐을 가능성도 있다 |
| 다음 확인 | 작업 XML, 실제 실행, 변경 승인 기록을 비교한다 |

**확인할 결과:** 결론에 사용한 문장마다 근거 이벤트의 식별자나 파일 위치를 붙일 수 있어야 합니다.

## 5단계 — 대응을 결정하고 결과를 검증하기

조치의 목적을 먼저 적습니다. 진행 중인 확산을 막으려는 것인지, 노출된 계정을 보호하려는 것인지 구분해야 합니다. 장비 격리, 계정 제한, 비밀값 교체와 설정 복원은 업무 영향 및 증거 보존과 함께 판단합니다.

실습에서는 조치를 실행하는 대신 “필요한 근거 → 제안 조치 → 성공 확인 방법”을 작성합니다. 예를 들어 인증 경로를 제한했다면 의심 연결이 줄었는지뿐 아니라 정상 업무가 유지되는지도 확인해야 합니다.

## 6단계 — 조사 메모 완성하기

다음 여섯 항목을 각각 1~3문장으로 남깁니다.

1. 조사 시작 근거와 대상 기간
2. 확보한 자료와 확보하지 못한 자료
3. 확인된 행동과 출처
4. 가능한 설명과 아직 구분하지 못한 부분
5. 실행한 조치 또는 제안 조치
6. 다음 조사 담당자와 필요한 자료

**완료 기준:** 다른 분석가가 메모만 보고 같은 근거를 찾아갈 수 있고, 확인되지 않은 내용을 사실로 읽지 않아야 합니다.

## 막힐 때의 점검 순서

로그가 없다면 시간대, 장비, 감사 설정, 보존 기간, 수집 경로를 확인합니다. 의심 항목이 너무 많다면 최초 근거와 연결되는 계정·장비·시간으로 범위를 좁힙니다. 증거가 충돌하면 어느 하나를 지우지 말고 시계 오차와 수집 지점의 차이를 기록합니다.
