## Hayabusa의 역할

Hayabusa는 Windows 이벤트 로그에서 Sigma 기반 탐지와 타임라인 생성을 수행하는 도구입니다. 이미 확보한 EVTX를 빠르게 분류하고 조사할 시간·장비·계정을 찾는 데 활용할 수 있습니다.

## 분석 순서

1. EVTX 원본과 분석 사본을 구분하고 수집·해시 기록을 남깁니다.
2. 설치한 Hayabusa의 버전·규칙·설정과 도움말을 확인합니다.
3. 타임라인을 생성해 높은 우선순위의 결과를 분류합니다.
4. 관련 이벤트의 원문, 채널과 실제 필드를 확인합니다.
5. 프로세스·인증·지속성·네트워크 기록으로 전후 행동을 연결합니다.

## 결과를 해석하는 기준

| 결과 | 추가로 확인할 것 |
| --- | --- |
| 높은 심각도 탐지 | 규칙의 조건과 정상 관리 행위 |
| 같은 장비의 여러 경보 | 동일 행동의 중복 탐지인지 여부 |
| 타임라인의 공백 | 로그 보존·감사 설정과 수집 누락 |
| 낮은 탐지 수 | 실제 위협 부재인지 관찰 범위 부족인지 |

경보는 분석 우선순위를 주는 결과입니다. 악성 여부의 최종 결론은 원문과 행동 맥락을 함께 검증해야 합니다. 규칙 버전이 바뀌면 탐지 결과도 달라질 수 있어 분석 시 사용한 버전을 남깁니다.
