## 장비의 상태부터 파악하기

배포판·버전, 호스트 이름, 시스템 시간·시간대, 부팅 시점과 역할을 확인합니다. 살아 있는 장비에서 명령을 실행하면 새로운 프로세스와 기록이 생기므로 수집 작업을 남깁니다. 중요한 휘발성 자료는 재부팅이나 프로세스 종료 전에 보존 여부를 판단합니다.

## 조사할 자료

| 영역 | 확인할 것 | 한계 |
| --- | --- | --- |
| 프로세스 | PID·PPID, 사용자, 실행 경로와 인자 | 종료된 프로세스는 현재 목록에 없음 |
| 네트워크 | 연결, 리스닝 포트와 소유 프로세스 | 현재 상태와 과거 통신은 다름 |
| 인증 | journal, 배포판별 인증 로그 | 설정·회전·보존 조건에 따라 누락 |
| 감사 | auditd와 감사 규칙 | 사전에 기록되지 않은 행위는 복원 불가 |
| 파일·지속성 | 서비스, timer, cron, 키와 실행 파일 | 시간 정보는 다른 증거와 교차 확인 |

`/proc`는 커널이 제공하는 현재 프로세스·시스템 정보의 인터페이스입니다. 디스크 이미지만 분석할 때 당시의 `/proc` 상태를 그대로 기대할 수 없습니다.

## 읽기 전용 상태 확인 예시

```bash
date --iso-8601=seconds
uname -a
ps -eo pid,ppid,user,lstart,args --sort=pid
ss -tupna
journalctl --since "2026-10-07 00:00:00" --until "2026-10-07 01:00:00" --utc
```

날짜는 예시이며 장비 시간대를 확인한 뒤 조사 구간으로 바꿉니다. 프로세스 세부 정보와 journal 접근에는 추가 권한이 필요할 수 있습니다. 조회 결과는 별도의 수집 기록과 함께 보존합니다.

## 분석의 연결점

의심 프로세스의 부모·계정·파일 경로를 확인하고 동일 시간대의 로그인과 서비스 시작 기록을 비교합니다. 외부 연결은 정상 업데이트·모니터링과 구별하고, 다른 호스트에서의 같은 계정 인증도 조사합니다.
