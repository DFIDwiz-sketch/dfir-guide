## 1일차의 연결 구조

SOC의 임무·권한을 정하고 관측 가능한 자산과 자료를 확인합니다. 이벤트에서 탐지 조건이 맞으면 경보를 검토하고 정상 설명·관련 행동·영향을 조사합니다. 사건 관리에 근거와 남은 작업을 기록하고 TIP 정보로 보강합니다. SIEM과 자동화는 이 흐름을 지원합니다.

## 핵심 구분 다시 확인하기

| 비교 | 설명해야 할 차이 |
| --- | --- |
| 이벤트 / 경보 | 관찰된 발생 / 탐지 조건의 결과 |
| 이상 / 악성 | 비교 기준과 다름 / 해로운 행동의 근거 |
| SIEM / 사건 관리 | 검색·탐지 / 조사·작업·조치 기록 |
| Observable / 악성 IOC | 조사 값 / 근거와 맥락이 있는 악성 관련 값 |
| 정보 Feed / 인텔리전스 | 입력 자료 / 방어 결정에 맞춘 분석 |
| 자동화 성공 / 대응 성공 | 실행 결과 / 실제 피해 감소 확인 |

## 한 장의 결과물 만들기

가상 외부 접속 경보 한 건을 고르고 대상·기간·원본, 정상 설명, 사건 전환 조건, 추가 수집 담당, 인텔리전스 출처와 최종 인계문을 씁니다.

필수 결과물은 운영 범위표, 관측 지도, 분류표, 사건 메모, 정보 카드와 탐지·자동화 조건입니다. 도구가 없어도 문서로 작성할 수 있습니다.

## 스스로 확인할 항목

자료 출처를 원문까지 되돌아갈 수 있는지, 사실·가설·미확인을 구분했는지, 담당과 완료 조건이 있는지 확인합니다. 알지 못하는 영역은 관측 공백으로 적습니다.

**완료 기준:** 다른 분석가가 같은 자료로 판단을 재확인하고 다음 작업을 할 수 있습니다. 이어지는 [Elastic 실습](bt1-elastic-lab.html)에서 검색 기본기를 적용합니다.
