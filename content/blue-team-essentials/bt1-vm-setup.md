## 실습 목표와 범위

이 활동은 교재의 가상 머신 준비 주제에 대응하는 자체 준비 절차입니다. 제공되지 않은 원본 VM·이미지·비밀번호를 추정하지 않습니다. 실제 도구가 없어도 가상 로그와 메모만으로 1일차를 진행할 수 있습니다.

## 1단계 — 사용할 환경 선택하기

문서 학습은 텍스트 편집기, 도구 학습은 권한 있는 시험 VM, 전체 네트워크 학습은 별도 랩으로 나눕니다. VM 제품과 OS 이미지는 공식 출처를 사용하고 CPU·메모리·디스크 조건을 해당 제품 문서에서 확인합니다.

| 구분 | 먼저 확인할 것 |
| --- | --- |
| 분석 PC | 파일 읽기·브라우저·메모 도구 |
| 시험 VM | 용도·OS·자원·복구 지점 |
| 네트워크 | NAT·Host-only·Internal·Bridged 중 실제 연결 |
| 도구 서비스 | 접속 주소·계정 권한·시험 자료 |
| 원본 폴더 | 변경하지 않을 자료와 해시 |

## 2단계 — 연결과 복구 조건 기록하기

실습 VM이 업무망과 어떤 경로로 연결되는지 적습니다. 스냅샷은 되돌림에 도움이 되지만 모든 외부 서비스와 공유 디스크까지 복구하는 것은 아닙니다. 공유 폴더·클립보드·외부 접속이 실습 목적에 필요한지도 확인합니다.

실습 범위와 허용 작업이 정해지기 전 공격 동작을 실행하지 않습니다. 여기서는 정상 파일·정상 조회·가상 자료만 사용합니다.

## 3단계 — 시간과 자료 확인하기

호스트·VM·분석 도구의 시간대와 UTC 시각을 기록합니다. 자료용 폴더를 original, working, notes로 나누고 파일의 출처·다운로드일·해시를 적습니다. 파일을 열어 JSONL 줄과 메일 헤더가 실제 존재하는지 확인합니다.

## 4단계 — 정상 동작 한 개 검증하기

브라우저의 정상 시험 페이지 접속 또는 가상 로그 한 줄 읽기를 수행합니다. 사용한 장비, 시각, 확인한 결과와 실패한 항목을 기록합니다. 로그인 화면이 열렸다고 데이터 수집까지 정상이라고 판단하지 않습니다.

**완료 기준:** 환경표·복구 방법·시간 기준·원본 위치와 정상 시험 기록을 확보합니다.

**막힐 때:** 파일 경로 → 도구 실행 → VM 자원 → 네트워크 모드 → 접속 권한 순서로 확인합니다.

## 최신 보강과 실무 연결

현재 환경의 설치 절차는 [GOAD-Light 설치](goad-light-install.html)와 [수집 검증](goad-light-telemetry.html)을 선택해 참고합니다. 교재의 2022년 도구 버전·화면을 현재 버전의 기본값으로 가정하지 않습니다.
