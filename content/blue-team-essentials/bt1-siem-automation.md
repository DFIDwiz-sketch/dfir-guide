## SIEM은 수집 자료를 판단에 연결한다

SIEM(Security Information and Event Management, 보안 정보·이벤트 관리)은 여러 출처의 로그와 제품 경보를 검색·연관 분석·시각화하고 탐지에 사용하도록 지원합니다. 수집했다고 자동으로 의미가 같아지는 것은 아닙니다. 필드·시각·계정·자산 식별자의 정규화와 자료 품질 관리가 필요합니다. SIEM의 수집 범위 밖 행동이나 보관하지 않은 원문을 검색으로 만들어낼 수는 없습니다.

공통 사례에서 SIEM은 로그인 D05와 메일 설정 D07을 같은 계정·세션으로 찾아주는 역할을 합니다. 사건 관리에서는 D11·D12의 확인과 D13·D14의 조치 결과를 기록합니다. TIP는 관측값에 맥락을 붙이고, SOAR는 승인된 반복 조회와 작업 연결을 도울 수 있습니다. 도구 역할을 섞지 않아야 탐지와 대응의 책임이 명확해집니다.

## 유스케이스는 검색식보다 크다

“새 장치” 검색식 하나는 후보를 찾을 수 있지만 왜 중요한지, 어떤 자료가 필요하고 누가 무엇을 할지는 설명하지 못합니다. 유스케이스에는 보호할 업무, 탐지 대상 행동, 필요한 자료·필드, 논리·시간 범위, 정상 예외, 검증 사례, 담당·대응과 유지 관리가 포함됩니다.

| 요소 | 교육용 작성 예 |
| --- | --- |
| 목표 | 미승인 세션 뒤 메일 설정 변경을 조사 |
| 자료 | 인증·SaaS 설정 감사, 계정·세션·시각 |
| 조건 | 새 장치 로그인 후보와 같은 세션의 전달 설정 |
| 예외 | 승인된 장치 교체와 업무용 전달 규칙 검토 |
| 분석 | 사용자·운영자 확인, 다른 세션·실제 전달 범위 |
| 대응 | 권한 있는 담당의 조치와 효과 검증 |
| 검증 | 양성·정상·누락·지연·중복 사례 |

이 학습의 시간 창은 예시입니다. 모든 조직에 같은 분·건수를 적용하는 규칙이 아닙니다. 자료 지연과 정상 작업 패턴을 확인하고 시험해야 합니다.

## 검색과 탐지를 구별하기

KQL은 Kibana의 필터 언어입니다. 필드 조건과 AND·OR·NOT으로 대상을 좁힐 수 있지만, 그 자체로 세션 간 조인·집계·자동 경보 생성까지 모두 수행하는 것은 아닙니다. 두 종류의 이벤트를 검색한 뒤 같은 세션인지 분석하는 활동과, 운영용 상관 규칙 구현은 별개입니다.

~~~text
dataset: "bt1-case-v2" AND account: "learner"
dataset: "bt1-case-v2" AND session_id: "S002"
dataset: "bt1-case-v2" AND record_type: "alert"
~~~

세 쿼리는 각각 계정, 세션, 경보를 찾는 필터입니다. 기본 최근 시간 범위에서는 고정 날짜의 학습 자료가 나오지 않을 수 있으므로 먼저 날짜 범위를 맞춥니다. 실제 입력 과정과 기대 ID는 마지막 Elastic 실습에서 확인합니다.

## 자동화와 오케스트레이션의 차이

자동화는 반복되는 한 작업을 기계가 수행하게 하는 것이고, 오케스트레이션은 여러 작업과 시스템의 순서·분기·의존성을 연결합니다. 계정 정보 조회를 자동화할 수 있고, 경보 → 조회 → 판정 → 승인 → 조치 → 결과 검증의 연결을 설계할 수 있습니다.

조회 실패는 정상 판정이 아니며 조치 요청 성공은 효과 확인이 아닙니다. 권한·시간 제한·재시도·중복 방지·실패 인계를 포함해야 운영에 쓸 수 있습니다. 처음에는 읽기 전용 조회와 작업 생성부터 자동화하고, 변경 조치는 승인과 검증을 포함해 범위를 정합니다.

## 지식 저장소와 코드 저장소

설명·정상 맥락·조사 노하우는 관리되는 지식 문서에, 탐지 규칙·스크립트·설정·시험 자료는 버전 관리 저장소에 둘 수 있습니다. 문서와 코드의 버전·담당·변경 이유를 연결하면 사건 뒤 개선을 재현할 수 있습니다. 비밀키와 인증 정보를 예제나 저장소에 넣지 않습니다.

## 학습 활동과 최신 보강

워크북의 탐지 설명서를 채우고 실패·지연·중복 테스트를 추가합니다. 현재 ASD의 SIEM·SOAR 지침을 참고해 수집 품질과 유지 관리까지 포함하세요. 두 분할 학습에서 유스케이스 검증과 자동화 실패 처리·지식 관리를 자세히 다룹니다.
