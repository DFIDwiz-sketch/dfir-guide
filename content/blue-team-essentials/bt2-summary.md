## 2일차에서 연결해야 할 지식

네트워크 구조는 수집 범위를 결정하고 수집 범위는 분석 결론의 한계를 결정합니다. DNS는 이름·주소·서비스를 연결하고 HTTP는 자원 요청·응답을, SMTP는 전달 경로·작성자 도메인을 보여줍니다. DHCP와 원격 관리 프로토콜은 네트워크 주소를 자산·계정·행동 조사로 이어 줍니다.

12개 교재 장과 19개 상세 글을 읽은 뒤에는 프로토콜 이름을 외우기보다 같은 사건을 여러 자료로 설명할 수 있어야 합니다. 자체 사례는 해설을 위한 제한된 관측이며 실제 공격 성공을 재현하는 자료가 아닙니다.

## 공통 사례의 조사 시간표

| 흐름 | 자료 | 관측 | 미확인·추가 조사 |
| --- | --- | --- | --- |
| 주소 배정 | N01 | 당시 WS-024의 주소 임대 | 실제 사용자·프로세스 |
| 메일 수신 | N02·EML | 인증 도메인 불일치·경고 전달 | 클릭·원인 계정·최초 작성자 |
| 조회·이동 | N03~N06 | DNS·302·별칭·주소 | 사용자 의도·인과관계 |
| 파일 응답 | N07·N08 | 무해 문서와 후보 경보 | 단말 저장·실행 |
| DNS 후보 | N10~N13 | 미승인 리졸버·고유 TXT 질의 | 앱·실제 데이터·정상 승인 |
| POST | N15 | 4096바이트·202 | 내용·업무 목적·완료 |
| 정상 대조 | N14·N16~N18 | 정책 TXT·모니터 주기 | 관측 범위 밖의 다른 행동 |
| 암호화 | N19·N20 | QUIC·TLS/ECH 메타데이터 | 실제 자원·앱·본문 |
| 내부 연결 | N21 | SMB 연결 | 계정·공유·명령 실행 |
| 수집·후속 | N22·N23 | 드롭·제한·Hunt 요청 | 단말 조사 결과 |

## 중요한 구분

DNS 조회와 웹 접근, 웹 접근과 파일 실행은 다릅니다. 수신 경계의 peer IP와 최초 작성자도 다릅니다. SPF·DKIM pass와 From 정렬, DMARC pass와 내용 안전성도 별개입니다. 연결·요청·응답·처리 완료·영향을 각각의 자료로 입증합니다.

자료가 없을 때는 그 행동이 없었다고 말하기 전에 센서 위치·암호화·수집 길이·드롭·보관 기간을 검토합니다. “미확인”은 분석 과정의 상태이며 정상 또는 악성의 대체 단어가 아닙니다.

## 2022년 교재에서 현재로 보강한 항목

| 주제 | 현재 학습에 추가한 내용 |
| --- | --- |
| 수집 | SPAN·TAP 용량·사각지대·실제 드롭, Flow와 원문 차이 |
| DNS | IPv6·SVCB/HTTPS·DoT/DoH/DoQ, DNSSEC와 기밀성 구별 |
| HTTP | API 자원·헤더 신뢰·스트림, HTTP/3와 QUIC |
| TLS | TLS 1.3 인증서·세션 비밀값·2026년 ECH 표준 |
| 메일 | 신뢰 경계·RFC 8601·2026년 DMARC 개정 |
| 원격 관리 | SMB 기본값 차이·관리 tenant·정상 도구 오용 |

표준 발행과 실제 조직 배포는 다르므로 버전·설정·승인·관측으로 확인합니다. 특정 제품이나 오래된 목록을 최신 운영 사실로 간주하지 않습니다.

## 결과물로 남기기

[워크북](downloads/blue-team-day2-workbook.md)에 수집 지도, DNS 경로, HTTP 거래, 메일 신뢰·정렬, 자산 임대 연결과 사건 요약을 작성합니다. 각 후보에 출처·ID·시각·정상 가능성·미확인·다음 조사·조치 범위를 적습니다. 마지막 SMTP 실습까지 수행하면 실행 없이 첨부와 헤더를 분석한 기록도 남습니다.

현재 자료로 침해 또는 유출을 확정하지 않습니다. 후보 경로의 원인 앱·계정·내용·서버 결과를 확인하기 위해 추가 조사하는 상태입니다. 조치 요청을 내는 경우에는 근거와 정상 영향, 승인 담당과 효과 확인 방법을 포함합니다.
