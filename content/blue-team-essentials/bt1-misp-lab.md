## 실습 목표와 범위

이 실습은 값에 맥락을 붙이고 상관·공유·탐지 사용을 검토하는 활동입니다. 실제 위협 피드 동기화나 외부 차단을 수행하지 않습니다. [워크북](downloads/blue-team-day1-workbook.md)의 정보 카드를 먼저 작성하고, 승인된 MISP 교육 환경이 있으면 해당 기능에 대응시킵니다. 환경이 없으면 동일한 구조의 카드로 완료할 수 있습니다.

MISP의 Event는 인텔리전스 묶음이며 보안 제품의 이벤트 한 건이나 사건 관리의 Case와 다릅니다. 모든 원시 로그 16행을 개별 MISP Event로 가져오는 실습이 아닙니다. 판단에 필요한 값과 맥락을 선별합니다.

## 1단계 · 초안 Event 작성

제목은 `EDUCATION · 계정·메일 설정 사례`로 하고 가상 자료임을 설명합니다. 관측 날짜와 출처는 D05·D07·D11·D12입니다. 세션·미승인 변경의 관계, 실제 메시지 전달 범위 미확인, 외부 평판 평가 대상이 아니라는 제한을 적습니다.

교육 환경의 Event 생성 권한과 배포 기본값을 먼저 확인합니다. 외부 동기화가 연결된 운영 환경에 연습 자료를 발행하지 않습니다. 가상 사례는 교육 환경 내부에서 다룹니다.

## 2단계 · 속성과 설명 선택

| 값 | 기록할 역할·출처 | 학습에서의 사용 |
| --- | --- | --- |
| 192.0.2.80 | D05·D07의 출발 IP, 문서용 대역 | 유형·맥락 기록, `to_ids` 끔 |
| learner | 조사 대상 가상 계정 | 내부 맥락, 지원 필드·설명 사용 |
| S002 | 로그인과 설정 변경의 세션 연결 | 내부 관계 기록 |
| archive@example.invalid | D07의 교육용 전달 대상 | 설정 변경 맥락, 자동 차단 제외 |

IP의 역할을 반영한 유형을 선택하되 실제 UI가 제공하는 유형과 카테고리를 확인합니다. 계정·세션을 지원하지 않는 유형으로 강제로 넣지 않습니다. 가상 값의 평판을 인터넷에서 조회해 악성이라고 판정하지 않습니다.

## 3단계 · 태그·Object·공유 검토

설명만으로 충분한지, 관계를 표현하는 Object가 필요한지 검토합니다. Taxonomy 태그는 실제 의미를 이해한 뒤 적용합니다. 공격자 그룹을 알 수 없으므로 이름이 유명하다는 이유로 Galaxy를 붙이지 않습니다. 공유 범위는 교육 내부로 제한하고 현재 TLP와 제품 배포 설정의 관계를 확인합니다.

`to_ids`는 맥락 자료를 모두 탐지 지표로 내보내는 버튼이 아닙니다. 이번 값들은 합성 교육 자료이므로 꺼 둡니다. 실제 인텔리전스를 사용할 때도 출처·정확성·유효 기간·경고 목록·소비 시스템의 기대 형식을 검토해야 합니다.

## 4단계 · 상관 결과 해석

교육용 두 번째 카드에 같은 IP를 넣었다고 가정해 관계를 설명합니다. 두 카드의 공유 값, 기간, 역할이 같거나 다른지 적습니다. 같은 값이 있다고 같은 공격자나 사건으로 확정하지 않습니다. 이 활동은 실제 외부 상관 결과를 만들어 내는 것이 아니라 상관 해석을 연습하는 과정입니다.

운영 환경에서 상관 결과가 나오면 관련 Event의 원문·출처·시각·역할을 검토합니다. 이미 검토한 정보가 다른 피드로 재전달된 것일 수 있으므로 독립된 근거인지 확인합니다.

## 5단계 · 피드백과 최종 검토

실제 관측 피드백을 남길 때는 값·시각·출처·판정 근거를 연결합니다. 교육용 Sighting이나 피드백은 가상임을 표시합니다. 실습 완료를 위해 실제 악성 관측을 꾸며내지 않습니다. 발행 전 Event·Attribute의 배포 범위와 탐지 사용 설정을 다시 확인합니다.

기대 결과는 Event 초안 또는 정보 카드 하나, 유형·역할·출처가 있는 값, 미확인 범위, 공유와 탐지 사용의 이유입니다. 다른 분석가가 왜 이 IP를 악성 목록에 넣지 않았는지 설명할 수 있어야 합니다.

## 자주 생기는 문제

카테고리·유형 불일치, 표시용 defang 값을 원래 값처럼 입력, 맥락 자료의 `to_ids` 일괄 활성화, 상관을 공격자 귀속으로 해석하는 오류를 확인합니다. 데이터 양보다 의미와 소비 조건이 중요합니다.
