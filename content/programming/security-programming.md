## 분석 문제를 작은 프로그램으로 바꾸기

Python으로 파일·문자열·JSON·CSV를 처리하는 것부터 시작합니다. 수동으로 반복하던 로그 분류나 타임라인 정규화를 코드로 만들고 입력 누락·잘못된 인코딩·시간대를 처리합니다.

## 언어별 학습 목적

| 단계 | 배울 내용 | 결과물 |
| --- | --- | --- |
| Python | 파일, 자료구조, JSON·CSV, 예외 처리 | 로그 요약·필드 정규화 프로그램 |
| 분석 자동화 | API, 배치 처리, 출력 검증 | 재현 가능한 분석 파이프라인 |
| C | 타입, 포인터, 배열, 구조체, 메모리 | 작은 정상 프로그램과 디버거 관찰 |
| 시스템 연결 | 프로세스, 모듈, API·시스템 호출 | 동작과 호스트 흔적의 대응표 |
| 어셈블리 | 레지스터, 호출 규약과 제어 흐름 | 함수 동작을 설명하는 역분석 노트 |

이 순서는 권장 학습 설계입니다. C와 어셈블리를 배우는 목적은 메모리와 실행 흐름을 이해하는 것입니다. 언어별 문법만 외우기보다 같은 동작을 소스·디버거·로그에서 비교합니다.

## 처음 만들 프로젝트

- JSONL 로그에서 이벤트 종류와 파싱 실패 수 집계
- CSV의 시각·장비·계정 필드를 일관된 출력으로 정리
- 확보한 파일 사본의 해시와 분석 결과 목록 생성
- 가상 사건 자료의 타임라인 생성과 누락 필드 보고

[Python 로그 파싱 예시](python-log-parser.html)에서 실제 실행할 수 있는 작은 프로그램을 시작할 수 있습니다.

## 검증 습관

정상 입력뿐 아니라 빈 파일, 누락 필드, 잘못된 JSON과 다른 인코딩을 시험합니다. 실패한 레코드를 조용히 버리지 않고 개수와 원인을 남깁니다. 원본을 덮어쓰지 말고 분석 결과를 새 파일로 저장합니다.
