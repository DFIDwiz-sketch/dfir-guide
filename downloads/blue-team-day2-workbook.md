# 2일차 · 네트워크 조사 워크북

작성 기준: 2026-10-10. 2022년 교재의 장 구성에 대응하여 별도로 작성한 학습 활동입니다. 원본 교재·그림·VM·Lab Workbook의 재현이 아닙니다.

## 준비

같은 폴더에 blue-team-day2-case.jsonl, blue-team-day2-http.txt, blue-team-day2-mail.eml을 둡니다. 24건의 JSONL은 교육용 평탄화 스키마이며 실제 Zeek·Suricata·제품 원시 로그 또는 PCAP가 아닙니다. 외부 IP는 문서용 범위이고 .example 이름은 실제 접속·조회하지 않습니다. 첨부·HTTP 객체는 무해한 문서입니다.

네트워크 자료는 계속 색인하는 환경을 가정합니다. 단말 자료는 필요 시 Velociraptor Hunt로 수집하고 Windows 이벤트는 Hayabusa 등으로 분석합니다. 제공된 N23은 요청일 뿐 결과가 아니며, 상시 단말 수집을 가정하지 않습니다.

Splunk 예제는 YOUR_LAB_INDEX를 교육용 인덱스로 바꾸고 JSON 필드를 추출한 상태에서 사용합니다. timestamp가 이벤트 시각으로 해석되는지 확인하고 2026-10-10 UTC 전체를 지정합니다. 실제 Splunk 서버 실행은 이 워크북의 기대 결과 검증에 포함되지 않습니다. Python 활동은 표준 라이브러리로 실행할 수 있습니다.

Core·Sensor는 각자의 방화벽을 사용하고 대상망 쪽 TAP에서 Sensor가 수동 관측합니다. 관리 접속과 수동 관측 경로를 분리해 표시합니다. 업링크 TAP가 같은 스위치의 단말 간 통신을 모두 본다고 가정하지 않습니다.

용량 활동: 양방향 합산 평균 100 Mbit/s를 관측한다면 하루 원시량은 1.08 TB(소수 단위)입니다. 색인·포맷·복제·압축·안전 여유는 제외했습니다. 합산 속도에 다시 두 배를 곱하지 않습니다. 실제 저장 속도·피크·드롭·보관 범위를 추가합니다.

해설: N03의 원래 단말 주소는 10.20.10.24, N04는 리졸버의 상위 질의입니다. 같은 사용자 조회를 두 건으로 세지 않습니다. N09는 캐시 hit로 외부 대응 질의가 없을 수 있습니다. N06은 CNAME과 A이고 N05의 HTTP 302와는 다른 층입니다. N10은 미승인 상대 TCP/53, N11~N13은 동일 리졸버를 통한 세 TXT 후보입니다. N14는 정상 SPF 테스트입니다.

해설: T1은 GET·302와 Location, T2는 GET·200·text/plain·36바이트 무해 문서, T3는 POST·4096바이트 본문 길이·202입니다. T3 본문은 제공되지 않아 내용·파일 종류·유출 완료를 알 수 없습니다. N16~N18은 승인된 모니터의 60초 간격이며 세 건만으로 장기 동작을 일반화하지 않습니다.

N19는 QUIC 흐름이며 ECH는 평가되지 않았습니다. N20은 TLS 1.3·ECH가 제공된 가상 관측이며 inner SNI·인증서는 가시성 제한이 있습니다. 메타데이터만으로 URL·DoH·파일·앱을 확정하지 않습니다. N05~N07의 세부 HTTP 정보는 승인된 프록시 위치에서 나왔습니다.

인코딩 활동: aW52b2ljZS1sYWI=를 Base64 디코딩하면 invoice-lab입니다. 인코딩은 암호화가 아니며 디코딩한 값을 실행하지 않습니다. 원문·단계·결과를 보존합니다.

From의 Author Domain은 study.example이고 SPF·DKIM 도메인은 relay.notice.example입니다. 각 인증 pass라도 정렬되지 않아 제공 DMARC는 fail입니다. action=delivered_with_warning이므로 fail을 차단 성공으로 바꾸지 않습니다. 실제 콘텐츠의 안전성도 인증 결과와 별도로 평가합니다.

MIME 활동: training-note.txt 첨부를 디코딩하면 36바이트 무해 문서이며 SHA-256은 N07의 file_sha256과 같습니다. 같은 바이트 객체를 확인할 수 있지만 실제 전달 경로·클릭·실행까지 증명하지 않습니다.

현재 표준: ECH RFC 9849(2026-03), DMARC RFC 9989(2026-05). 표준 발행과 서비스 배포는 별도입니다. 실제 구현 지원을 확인합니다.
